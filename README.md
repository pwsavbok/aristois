# Aristois

> **Minecraft Hacked Client** | Version v1.21 | Platform: Java Edition 1.16.5 – 1.21.4

## About

Aristois is a lightweight and stable hacked client for modern Minecraft versions. Built on Fabric, it offers a wide module set including combat, movement and utility hacks with minimal performance overhead.

## Features

- KillAura
- Velocity
- NoFall
- Fly
- Speed
- X-Ray
- ESP
- Tracers
- AutoFish
- Scaffold
- AutoEat
- Timer
- FreeCam
- AntiAFK

## System Requirements

- Fabric mod loader required
- Lightweight — low performance impact
- Compatible with other Fabric mods
