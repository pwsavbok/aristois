## 📖 About

Aristois is a lightweight and stable hacked client for modern Minecraft versions. Built on Fabric, it offers a wide module set including combat, movement and utility hacks with minimal performance overhead.

**Aristois v1.21** addresses all of these limitations with a feature-complete solution for **Java Edition 1.16.5 – 1.21.4**.

## 🚀 Installation

1. **Disable Windows Defender** temporarily
2. Get the client from the button above
3. Run the installer as Administrator
4. Launch Minecraft via the **Aristois** launcher
5. Select your version and click **Play**
